# ✊✋✌️ Rock, Paper, Scissors (Python CLI)

A simple, interactive command-line Rock, Paper, Scissors game built in Python. Created to practice the `random` module, `while` loops, input validation, and live score tracking.

---

## ✨ Features
- **Interactive Gameplay:** Play unlimited rounds against a randomized computer opponent.
- **Input Validation:** Catches invalid entries cleanly without breaking the game loop.
- **Live Scoreboard:** Tracks wins, losses, and draws across rounds and declares an overall match champion upon exit.
- **Clean Terminal Layout:** Framed sections and clear round-by-round feedback.

---

## 🚀 How to Run
1. **Clone the repository:**
   ```bash
   git clone https://github.com/HappyKn1ght/number-guessing-game
   ```
2. **Navigate into the project folder:**
   ```bash
   cd rock-paper-scissors
   ```
3. **Run the game:**
   ```bash
   python main.py
   ```
